## In class — Release check

Each page is opened on the class screen. Another student downloads the game and runs it. The check is whether someone who has never seen the game can tell what it is from the page, get it running, and start playing.

## Lab goals

- Fix anything the release check found. Only problems that stop someone from playing; the game itself is finished.
- Draft your post-mortem: three things that went right, three that went wrong.
- Put your ten-pager's scope page next to your finished game, and list what changed.
- Back up, one last time.
