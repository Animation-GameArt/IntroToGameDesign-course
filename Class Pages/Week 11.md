# Week 11 — Studio — Core Loop

**GAME 1303**

Lectures are over. From today, class is a studio: a short stand-up, a short topic, and long stretches of building. This week's goal is a core loop that is complete and feels right.

## In class — Sprint review

Each student demos for two minutes: play the core loop once, name one thing that feels right, and name one thing that doesn't. The class and the instructor give one suggestion each. Keep to time. A demo that runs long takes studio time from everyone.

## Lab goals

- Fix the one thing you said doesn't feel right.
- Do a tuning pass: change the numbers behind your main action until it feels the way your ten-pager describes.
- Finish the features still missing for Alpha.
- Update your board, and back up before you leave.
