Week 16 · [Lecture] Week 16 · Instructor notes

In one sentence
Five minutes each, timed, with two minutes of questions, and the same closing question for everyone.

How it runs

  • Five minutes, timed. A visible timer keeps it fair.
  • Two minutes of questions from the class first, then the instructor.
  • The closing question for everyone: "What would you tell yourself in Week 3?" The answers are nearly always about scope, and hearing it from the whole class lands harder than hearing it from an instructor.
  • Push gently for specifics. If a student says "time management," ask what the time went to.
  • Praise honesty about what went wrong as much as polished results.

After the presentations

  • Ask the class what they'd change about the course, and write the answers down.
  • Note any per-game scripts worth promoting into the kits for next semester.
  • Remind students that Game & Simulation Group Project uses the same course scripts and kits.
