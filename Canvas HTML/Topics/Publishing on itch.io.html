Week 9 · [Lecture] Week 9

In one sentence
Each student's game lives on an itch.io page, private until Gold, so every milestone is a link anyone in class can open.

What this topic is for

Students create their page in Ex 08 and upload their first build. From then on, every milestone is submitted as a link to this page.

Key ideas

  • One page per game, created from the student's own free itch.io account.
  • Private, then public. The page stays private (or restricted) until Gold in Week 15, then becomes public.
  • Web builds play in the browser. Upload the Web build as a ZIP and mark it as playable in the browser. Desktop builds are uploaded as ZIP downloads.
  • Version each upload. Note the milestone in the upload's name, such as "First Playable" or "1.0".
  • The page is part of the game. Title, a one-line description, screenshots and controls are added at Gold.

In class

  1. Create a page live, upload a Web build, set it to private, and open it.
  2. Show where to find the page's link for Canvas.
