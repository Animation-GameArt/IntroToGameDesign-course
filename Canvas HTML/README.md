# Canvas HTML

These files are HTML copies of the course's Markdown pages, made for pasting into Canvas.

**Don't edit these files.** Edit the Markdown page, then rebuild:

```
python3 tools/build_canvas_html.py
```

## Using a page in Canvas

1. Open the `.html` file here on GitHub and click **Raw**. Select all and copy.
2. In Canvas, edit the page and switch to the HTML editor (the **</>** button below the text box).
3. Paste, then save.

The Canvas page's own title is the top heading, so these files start at heading level 2. Every table has a caption and column headers with a scope, so the Canvas accessibility checker has nothing to fix in them. Links to other Canvas items (assignments, discussions, other pages) are plain text, to be linked in Canvas.
