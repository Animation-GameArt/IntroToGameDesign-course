# Core Loops

**Week 1 · [[Lecture] Week 1](https://github.com/Animation-GameArt/IntroToGameDesign-course/blob/main/Class%20Pages/Week%2001%20-%20Lecture.md)**

> [!abstract] In one sentence
> The core loop is the small set of actions a player repeats from moment to moment, and it is the first thing to design and the last thing to cut.

## What this topic is for

Students arrive able to say whether they like a game, but not why. This topic gives them the first tool for saying why. By the end of the lecture each student should be able to describe the core loop of a game they know in one line, and use that line to judge their own ideas.

## Key ideas

- **A game needs rules, a goal and feedback.** Rules say what the player can do. The goal says what they're trying to do. Feedback tells them how they're doing.
- **The core loop is what the player does most.** Run, jump, collect. Aim, shoot, dodge. Read, choose, see the result. If a game were a sentence, the core loop would be its verb.
- **Loops nest.** A moment-to-moment loop (jump over a gap) sits inside a level loop (reach the flag), which sits inside a game loop (unlock the next world). Students' games are small, so the moment-to-moment loop matters most.
- **A good loop is easy to say and still interesting on the hundredth repeat.** If the loop takes a paragraph to explain, it's probably several loops, and the game is too big.
- **Mechanics, dynamics, aesthetics.** The MDA framework separates the rules the designer writes (mechanics), the behavior that comes out of them in play (dynamics), and what the player feels (aesthetics). Designers work from mechanics; players experience aesthetics. It's a useful vocabulary, not a formula.

## In class

1. Name five well-known games. For each, the class writes the core loop in one line, then compares answers.
2. Play a short game on the projector for two minutes. Students write its loop before discussion.
3. Ask: "What would you remove to make this game smaller without losing what makes it fun?" The answer is almost never part of the core loop.

## Common problems

| Students often… | Help them by… |
|---|---|
| Describe the story or the setting instead of the loop | Asking "what do your hands do?" |
| Describe ten features | Asking which one the player does every few seconds |
| Pick a loop that only works with a large world | Pointing them to the scope guidance on the [Genre Map](https://github.com/Animation-GameArt/IntroToGameDesign-course/blob/main/Guides/Genre%20Map.md) |
