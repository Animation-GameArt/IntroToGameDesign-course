# Final Build Checks

**Week 15 · [[Lecture] Week 15](https://github.com/Animation-GameArt/IntroToGameDesign-course/blob/main/Class%20Pages/Week%2015%20-%20Lecture.md)**

> [!abstract] In one sentence
> The released build is downloaded from the public page and played on a computer that isn't the developer's, because that's how every player will meet it.

## What this topic is for

The last technical check before Gold. Problems found here stop people from playing at all, so they come before any other fix.

## The checks

- [ ] Download the build from the public page, on a different computer.
- [ ] It starts at the title screen.
- [ ] Every scene is in the build.
- [ ] Sound plays, and the volume controls work.
- [ ] The game can be played to the end and won.
- [ ] The game can be quit.
- [ ] Saved progress and settings survive closing and reopening the game.
- [ ] The build is marked version **1.0**, so a later fix can be told apart.
- [ ] For Web builds: it runs in at least two browsers.
