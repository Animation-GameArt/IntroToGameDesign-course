# Store Pages

**Week 15 · [[Lecture] Week 15](https://github.com/Animation-GameArt/IntroToGameDesign-course/blob/main/Class%20Pages/Week%2015%20-%20Lecture.md)**

> [!abstract] In one sentence
> A visitor decides in seconds, so the store page has to say what the game is, show it being played, and make it easy to start.

## What this topic is for

At Gold, each student's itch.io page becomes public. The release check asks whether someone who has never seen the game can tell what it is and start playing.

## Key ideas

- **The first line is the logline** from the one-sheet. That's what it was written for.
- **Three screenshots of play,** each showing something different: the main action, the best-looking moment, and something that shows progress or variety. A title screen isn't a screenshot of the game.
- **Controls on the page.** Nobody reads them in the game.
- **A short description:** what it is, how to play, how long it takes.
- **Credits on the page,** or a note that they're in the game.
- **A cover image** for the itch.io listing, ideally showing the game's character or main action.
- **Playable in the browser** if possible. One click to play beats a download.

## In class

1. Open three well-known itch.io pages and note what each shows above the fold.
2. The release check: each page on the class screen, and a classmate starts the game from it.
